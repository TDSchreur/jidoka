A run's plan is now saved in the factory data folder (`plans/<run id>.md`, or `plans-<port>/` for a dashboard on another port) instead of the worktree's git directory or beside the worktree, so it outlives the worktree. `factory run begin` and `factory run inspect` show the path, and `factory run cleanup` leaves the plan. The dashboard Reader opens a run's own plan from the factory data folder, also after the worktree is gone, and no longer serves the old `<worktree>.factory-plan.md` or git-directory plan locations.
