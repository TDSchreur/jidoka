## Changed

- The test-first `implement-spec` skill used by `/factory` now works like `implement-spec-balanced` and `implement-spec-fast`: sequentially in the run's worktree and branch, one ticket at a time with `tdd`. It no longer asks for implementer or merger subagents, extra worktrees, a draft pull request or its own code review, so `/factory` no longer has to override it. The upstream license is still installed with it.
