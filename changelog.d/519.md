## Changed

- `jidoka run update` now takes metadata options without a positional status. Use `run block`, `run resume`, and `run rework` for those transitions. The run update API likewise accepts metadata only, with lifecycle actions posted to `/api/runs/<id>/lifecycle`. Upgrade the CLI, installed skills and dashboard together.
- Workflow mode is fixed once initialized. Jidoka assigns the Rework number and records the triggering finding, classification, and user decision when required.
