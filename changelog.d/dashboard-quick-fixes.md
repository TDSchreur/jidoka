## Changed

- The Needs you button is filled while a Run is waiting, and stays quiet when nothing is.
- Delete on cards and project rows, and Delete all, are quiet text buttons. The red Delete is kept for the confirmation dialog.
- The Theme control moved from the toolbar to the footer, next to the version.
- A project whose Runs are all done starts collapsed until you open it. The dashboard remembers that you opened it.
- On wide screens, an empty Stage cell is only as tall as its "No runs" line. On narrow screens, projects with no Runs in the selected Stage are left out, so "No runs" shows once.
- Status badges use sentence case ("Running", not "RUNNING"). Cards no longer prefix the activity and ticket with "Activity:" and "Ticket:", and the Stage descriptions under the column headings are gone; Help still explains the Stages.
- On a phone, Delete and Hide stay on the project's heading line.

## Fixed

- The connection dot pulses when the connection state changes, not on every refresh.
