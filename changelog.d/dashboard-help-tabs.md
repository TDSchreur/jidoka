## Changed

- The dashboard Help is now a large dialog with seven tabs: Overview, Stages, Workflows, Skills, Dashboard, Commands and Model routing. It explains the flow, each Stage, Rework and Needs you, how the three workflows differ, what each skill the flow uses does, how to read the board and the Run detail, the `factory` commands, and model routing. The tabs work with the arrow keys, Home and End, and each tab scrolls on its own.
