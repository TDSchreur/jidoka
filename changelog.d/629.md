## Added

- `jidoka run advance <id> --skip-ci --reason "<text>"` leaves Finish without a live CI result when CI cannot be read. Unlike `--force`, it skips only the CI check; the other gates still apply. The run records the completion as `ci-skipped`.

## Changed

- Azure DevOps errors from `jidoka pr wait` about a missing or invalid field now name the field and the response it came from.
