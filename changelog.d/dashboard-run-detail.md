## Added

- Select a Run's card on the dashboard to open its detail as a sheet on the right, over the board, showing every field of the Run: project, Stage, status, activity, ticket, blocking reason, Rework, last update and Run id. Close it with Escape, a click outside it or the Close button; focus returns to the card. The detail stays open and updates while the dashboard refreshes, and closes if its Run goes away. On screens 1024 pixels wide or narrower it fills the screen and the button reads Back.
