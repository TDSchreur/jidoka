## Changed

- `jidoka run rework` now takes one `--finding <id>=<wording|behavior>` for every open Finding (the old `--finding <id> --classification <c>` form is gone), and the lifecycle API's `rework` action takes a `findings` list of `{id, classification}`. The decision rule of ADR-0006 applies to the whole set: any `behavior` Finding makes the Rework need the user's `--decision` in Rework 3, whatever the order. An incomplete, repeated or unknown list is rejected without changing the run. New Rework records store `findings` as `{id, classification}` entries and no longer write `finding`; older records still load. Upgrade the CLI, installed skills and dashboard together.
