## Changed

- The run details sheet is now a route card: a header with the status, pull request and spec, then Define, Build, Check and Finish with their summaries, skills, activity reports, tickets and fresh tokens. A blocked run shows its reason in an amber status row, and token usage is a section that is open while the run is active. The sheet no longer shows the worktree path, the base commit or how long ago the pull request state was checked (`factory run inspect` still prints the worktree and base commit), and times use one short format. Build shows how many tickets are done and marks the current ticket as in progress, and reports that fit no station or ticket appear under Other reports.
