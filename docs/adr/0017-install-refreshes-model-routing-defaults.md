# Install refreshes model routing defaults

Install and automatic version refresh replace the per-user model routing policy with the current defaults for all agents. This keeps model choices current as available models change, at the cost of discarding custom routing; users can save and restore their custom policy. Doctor remains create-only for users who want a starter without overwriting a policy. Codex uses GPT-6.2 Sol for Define and Build and GPT-6.2 Astra for Check, balancing routine work with a stronger review model; Finish keeps GPT-6 Luna.
