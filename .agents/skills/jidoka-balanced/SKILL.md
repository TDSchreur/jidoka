# Jidoka Balanced

Start or continue the run using [jidoka-procedures](../jidoka-procedures/SKILL.md). Then run `jidoka run next <id>`, follow its instructions, and run `jidoka run advance <id>` when the stage is done. Repeat until the run is complete.
