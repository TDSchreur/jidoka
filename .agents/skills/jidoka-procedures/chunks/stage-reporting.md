## Run reporting

Record stage summaries and ticket status with `jidoka run update <id> running`; use `--current-ticket <reference>` while working on a ticket and clear it afterward. Record skill and activity reports at milestones. Mark a run blocked with `--blocking-reason` when outside input is needed. Never include secrets. For options and continuation details, consult `jidoka-procedures/chunks/run-reporting.md` in the installed skills. Use `jidoka run advance <id>` to leave a stage.
