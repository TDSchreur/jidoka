## Model routing

The coordinator retains its model. Apply routing only if the run’s recorded agent matches the agent you are using and `jidoka doctor` did not warn that the policy cannot apply. Otherwise use the coordinator model and report why routing was not applied. Hand routed work to fresh agents on the displayed model and effort, respecting the host's delegation and model permissions. Supply each agent the worktree, task, the saved plan or spec by its path or URL (which it reads itself, not a coordinator summary) and required skill; record the actual route or the reason routing was not applied in the stage summary. If the host rejects the selected model or effort, start the agent without either and report the fallback.
