# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies in all project spaces: issues, pull requests and any other discussion.

In short:

- Be respectful and welcoming. Give and accept constructive feedback gracefully.
- No harassment, discrimination, personal attacks, or publishing others' private information.
- Keep discussion focused on the project.

## Enforcement

Maintainers may edit or remove comments, issues and contributions that break this code, and may block contributors who do. To report a violation, use [GitHub's private vulnerability reporting form](https://github.com/TDSchreur/jidoka/security/advisories/new) and say it is a conduct report. Reports are handled privately.
