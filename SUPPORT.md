# Support

- **Questions and problems:** read the [README](README.md) and the [docs](docs/), and run `jidoka doctor` (see [the doctor guide](docs/doctor.md)).
- **Bugs and ideas:** open a [GitHub issue](https://github.com/TDSchreur/jidoka/issues/new/choose).
- **Security vulnerabilities:** report them privately, as described in the [security policy](SECURITY.md). Do not open a public issue.
