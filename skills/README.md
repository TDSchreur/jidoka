# Skills

The local workflow skills, one per workflow mode, live in the project skill discovery directory alongside `triage`:

- [`factory`](../.agents/skills/factory/SKILL.md) assesses the request and selects an execution workflow.
- [`factory-full`](../.agents/skills/factory-full/SKILL.md) grills, writes a spec and tickets, builds test-first with `tdd`, then runs code and security review.
- [`factory-balanced`](../.agents/skills/factory-balanced/SKILL.md) plans lightly with explicit acceptance criteria, builds with [`implement-spec-balanced`](implement-spec-balanced/SKILL.md) (implementation first, then behavior tests), and runs one initial code review with follow-up reviews of Rework fixes, plus a security review for security-sensitive diffs.
- [`factory-fast`](../.agents/skills/factory-fast/SKILL.md) plans lightly, builds without TDD using [`implement-spec-fast`](implement-spec-fast/SKILL.md), and skips the Check stage.

[`factory-procedures`](../.agents/skills/factory-procedures/SKILL.md) holds the procedures the three workflows share (run reporting, continuing a run, workspace, tracker setup, writing, pull request and CI); each workflow links to it as a sibling skill, so the link resolves in this checkout and in every installed layout, and keeps its own planning, testing, review and verification policy. `implement-spec-balanced` and `implement-spec-fast` are local implementation skills, and `implement-spec` is a local adaptation of the upstream skill (listed below); the remaining skill directories come from the upstream projects listed below. Each skill lives in its own directory with a `SKILL.md` and any supporting files. `factory install --agent codex` installs the selector, three workflows, `factory-procedures`, `triage`, `humanizer`, `setup-matt-pocock-skills`, and their required skills, including `tdd`, for Codex; `claude` and `copilot` are also supported, and a comma-separated list such as `codex,claude` installs for several agents. Each install replaces the bundled skill directories. `github-actions-hardening`, `rust` and `rust-best-practices` are used only to develop this project and are not installed. Other skills in this directory can be installed using the agent's normal installation process.

Local adaptations of upstream skills:

- `implement-spec` (from mattpocock/skills): the upstream skill runs implementer and merger subagents in separate worktrees, opens a draft PR and runs a code review. The adaptation builds the tickets sequentially in the run's existing worktree and branch, one at a time with `tdd`, runs the project's checks after each ticket, and leaves committing, the pull request and review to the calling workflow. Its MIT license is still installed with it.
- `pr` (from mattpocock/skills): the adaptation adds a step that runs the finished description through `humanizer` in embedded mode, keeping the template's sections, evidence and review findings intact. It also says in its description what the skill produces, adds optional template parts for linked tickets or the spec and for remaining review findings, gives a rule for the title, and aims the Summary guidance at a reviewer instead of a chat question. Its MIT license is still installed with it.
- `setup-matt-pocock-skills` (from mattpocock/skills): the adaptation adds an Azure Boards issue tracker option for any repository host, with an `issue-tracker-azure-boards.md` template whose work item types and states setup discovers from the project. Its MIT license is still installed with it.
