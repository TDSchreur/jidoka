# Skills

[`factory2`](../.agents/skills/factory2/SKILL.md) is the local workflow skill; [`factory2-fast`](../.agents/skills/factory2-fast/SKILL.md) uses lightweight planning for clear requests, skips the Check stage, and builds without TDD using [`implement-spec-fast`](implement-spec-fast/SKILL.md). They live in the project skill discovery directory alongside `triage` and `rust-best-practices`. `implement-spec-fast` is a local implementation skill; the remaining skill directories come from the upstream projects listed below. Each skill lives in its own directory with a `SKILL.md` and any supporting files. `factory2 install --agent codex` installs both workflows, `triage`, `rust-best-practices`, and their required skills, including `tdd`, for Codex; `claude` and `copilot` are also supported. Each install replaces the bundled skill directories. Other skills in this directory can be installed using the agent's normal installation process.

- [github/awesome-copilot](https://github.com/github/awesome-copilot), commit [`0fe6545`](https://github.com/github/awesome-copilot/tree/0fe6545b950671641b2b14b44eb56678fea6c6b4): `security-review` (called `security-scan` in the original Factory).

These instructions may invoke other skills or expect project-specific setup, so review them before use. Updates are manual: compare with upstream and copy the desired changes along with their supporting files.
