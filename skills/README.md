# Skills

The local workflow skills, one per workflow mode, live in the project skill discovery directory alongside `factory-triage`:

- [`factory`](../.agents/skills/factory/SKILL.md) assesses the request and selects an execution workflow.
- [`factory-full`](../.agents/skills/factory-full/SKILL.md) grills, writes a spec and tickets, builds test-first with `factory-tdd` (from upstream `tdd`), then runs code and security review.
- [`factory-balanced`](../.agents/skills/factory-balanced/SKILL.md) plans lightly with explicit acceptance criteria, builds with [`factory-implement-balanced`](factory-implement-balanced/SKILL.md) (implementation first, then behavior tests), and runs one initial code review with follow-up reviews of Rework fixes, plus a security review for security-sensitive diffs.
- [`factory-fast`](../.agents/skills/factory-fast/SKILL.md) plans lightly, builds without TDD using [`factory-implement-fast`](factory-implement-fast/SKILL.md), and skips the Check stage.

[`factory-procedures`](../.agents/skills/factory-procedures/SKILL.md) holds the procedures the three workflows share (run reporting, continuing a run, workspace, tracker setup, pull request and CI); each workflow links to it as a sibling skill, so the link resolves in this checkout and in every installed layout, and keeps its own planning, testing, review and verification policy. `factory-implement-balanced` and `factory-implement-fast` are local implementation skills, and `factory-implement` is a local adaptation of the upstream skill (listed below); the remaining skill directories come from the upstream projects listed below. Each skill lives in its own directory with a `SKILL.md` and any supporting files. `factory install --agent codex` installs the selector, three workflows, `factory-procedures`, `factory-triage`, `factory-setup`, and their required skills, including `factory-tdd`, for Codex; `claude` and `copilot` are also supported, and a comma-separated list such as `codex,claude` installs for several agents. Each install replaces the bundled skill directories. `github-actions-hardening`, `rust` and `rust-best-practices` are used only to develop this project and are not installed. Other skills in this directory can be installed using the agent's normal installation process.

Local adaptations of upstream skills:

- `factory-implement` (from mattpocock/skills): the upstream skill runs implementer and merger subagents in separate worktrees, opens a draft PR and runs a code review. The adaptation builds the tickets sequentially in the run's existing worktree and branch, one at a time with `factory-tdd`, runs the project's checks after each ticket, and leaves committing, the pull request and review to the calling workflow. Its MIT license is still installed with it.
- `factory-pr` (from mattpocock/skills): the adaptation says in its description what the skill produces, adds optional template parts for linked tickets or the spec and for remaining review findings, gives a rule for the title, and aims the Summary guidance at a reviewer instead of a chat question. Its MIT license is still installed with it.
- `factory-setup` (adapted from upstream `setup-matt-pocock-skills`): the adaptation adds an Azure Boards issue tracker option for any repository host, with an `issue-tracker-azure-boards.md` template whose work item types and states setup discovers from the project. Its MIT license is still installed with it.
